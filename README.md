\# Real-Time Hand Gesture Recognition System



\## Project Overview

This project is a real-time hand gesture recognition system developed using Python, OpenCV and MediaPipe.



It uses a webcam to detect hand landmarks, count fingers and recognize different hand gestures.



\## Features

\- Real-time hand detection

\- Hand landmark tracking

\- Finger counting

\- Recognition of 8 hand gestures

\- Support for detecting up to two hands

\- Live webcam display



\## Supported Gestures

1\. Open Palm

2\. Fist

3\. Peace

4\. Thumbs Up

5\. Thumbs Down

6\. OK

7\. Rock

8\. Call Me



\## Technologies Used

\## Installation



Install Python 3.12 and run these commands:



```bash

pip install opencv-python

pip install mediapipe==0.10.21

pip install numpy

```



\## How to Run



1\. Connect or enable your webcam.

2\. Open the project folder.

3\. Run:



```bash

python gesture\_recognition.py

```



4\. Show your hand in front of the camera.

5\. Try the supported gestures.

6\. Press Q to close the application.
